    3.2 结构优化

    图 5：结构优化Relaxtion设置

  • 部分参数解释如下：

    • Number of steps：结构优化步数上限，建议300步左右。

    Force tolerance：结构优化力阈值，建议0.01 eV/Å。

    Degrees of freedom：首次优化勾选Relax all，后续优化（看情况）可以勾选Relax atom positions。

    Constraints：结构优化约束，勾选Lattice constraints。设置如下图

    图 6：结构优化Lattice constraints设置

    图 7：结构优化Solver setting设置

  • 部分参数解释如下：

    • k-point sampling：能带计算k点网格，n1、n2、n3分别对应x、y、z方向的k点网格数，这个数x晶格常数a的值大概在40左右就行。 例如a=3Å，n1=12，n2=12，n3=12。那么是使用Gamma-centered还是Monkhorst-Pack网格(以下是网上的建议)。

    奇数的时候，m和g是一样的。

    k点小的时候一般是g，且用偶数。

    k点多的时候，用m的奇数，或者G的奇偶。

    cut-off：截断能设置，建议500eV，计算杂化时如果计算时间过久可以改成400eV。

    Symmtery：是否使用对称性计算。

    Convergence：勾选，Energy tolerance，建议1e-5。（根据计算要求精度调整）

    图 8：结构优化Physical settings设置

    Van der Waals:色散矫正（一般来讲是勾选，其他情况看着办），关于它的三种类型可以看这篇文章 DFT-D色散校正的使用。

    不同的人提出过不同的色散校正方法，如TS、XDM、VV10等，其中最成功、也是目前最为流行的是Grimme提出的DFT-D，有以下版本:

  • (1) JCC,25,1463(2004)：DFT-D1。已过时
  • (2) JCC,27,1787(2006)：DFT-D2。已过时
  • (3) JCP,132,154104(2010)：DFT-D3。比DFT-D2更严谨，整体精度更好，支持元素更多（支持从H到Pu），对几乎所有主流泛函都提供了参数，而且几乎不令计算耗时有任何增加，实现也很容易，如今几乎所有主流量化程序都支持DFT-D3
  • (4) JCP,147,034112(2017)：DFT-D4。比DFT-D3的改进在于可以考虑实际电子结构对色散校正能的影响，但计算方式复杂得多，目前只有较少程序支持

    • 最后是关于磁性的计算，没经验，只能自己摸索了。

    5 常用参数设置

    5.1 截断能设置

    收敛性测试的意义：原则上ENCUT（截断能）和KPOINTS越多越好，但我们需要在有限的计算时间和资源下找到一个尽可能符合计算精度的设置，因此需要通过做收敛性测试。

    一般情况下，截断能设置在400-500eV之间，具体数值可以根据收敛性测试结果调整，那么如何做收敛性测试，我选择MS软件进行演示。

      1、首先，先安装MS软件，教程可参考b站视频 ，版本可选择2024。（可能会有适配问题，可以降低版本，2025版本对CASTEP模块有GPU加速功能，有条件可以安装2025版本）

      2、打开MS软件，导入计算的结构文件，在导航栏的Modules中选择CASTEP，选择Calculation。

      3、在“Calculation”窗口的具体设置请自行学习，推荐个视频b站视频。

      我这边有一个案例，计算AlN表面生长石墨烯（原子数量为69）。关于脚本计算，我这边有个代码可做参考，新建一个TXT文件，将以下代码复制进去，将它的.txt后缀改为.pl后缀， 拖入MS后就可以了，具体要怎么用这个脚本，Run on Server为运行脚本，Script Job可以更改核数。

      关于脚本的红色部分，在Calculation”窗口的Run按钮右边有一个三角图标，点击后有个Copy Script， 在参数设置完后点击（操作的意义就是复制你的计算参数的代码），可粘贴替换掉红色部分

      #!perl

use strict;
use MaterialsScript qw(:all);

# initial files preparation
my $myDoc=$Documents{"AlN.xsd"};#定义要计算的模型文件
my $myStudyTable=Documents->new("energy-encut.std");#新建StudyTable存放计算结构，第一列是截断能，第二列是体系总能
my $mySheet=$myStudyTable->ActiveSheet;
$mySheet->ColumnHeading(0)="Enegy Cutoff(eV)";
$mySheet->ColumnHeading(1)="Final Enegy(eV)";

# castep single calculation
my $castep=Modules->CASTEP;
my $startEnergy=200;#测试起点:200 eV
my $endEnergy=500;#测试终点: 500 eV
my $intervalEnergy=20;#测试点间隔
my $sumIteration=($endEnergy-$startEnergy)/$intervalEnergy;

#循环计算每个截断能测试点的单点能
for(my $counter=0;$counter<=$sumIteration;++$counter){
        my $energyCutoff=$startEnergy+$intervalEnergy*$counter;

        $castep->ChangeSettings(
                Settings(Quality=>"Fine",
                UseCustomEnergyCutoff=>"Yes",
                EnergyCutoff=>$energyCutoff,
                FFTQuality => 'Fine', 
	        FFTFineGrid => 1.2, 
	        SCFConvergence => 1e-006, 
	        ParameterA => 2, 
	        ParameterB => 2, 
	        ParameterC => 1, #这里三个数值为k的网格设置，如代码所示为2x2x1
	        UseInsulatorDerivation => 'Yes', 
	        KPointDerivation => 'CustomGrid'));#这里设置截断能为测试点的截断能
        $castep->Energy->Run($myDoc);
        
        $mySheet->Cell($counter,0)=$energyCutoff;
        
        #read final energy from castep output files
        #下面这一段提取castep文件中的总能，即Final energy后面的结果
     my $finalEnergy; # 初始化能量变量
    foreach my $line (@{$Documents{"AlN.castep"}->Lines}) {
        # 正则匹配：捕获"Final energy = 数值"中的数值（兼容正负、小数/整数）
        if ($line =~ /^Final energy\s*=\s*([-+]?\d*\.\d+|\d+)/) {
            $finalEnergy = $1; # 捕获组1提取数值
            last; # 找到后退出循环，避免重复匹配
        }
    }
    
    # 输出并写入StudyTable
    if (defined $finalEnergy) {
        print $energyCutoff, "\t", $finalEnergy, "\n";
        $mySheet->Cell($counter, 1) = $finalEnergy;
    } else {
        print "警告：截断能$energyCutoff eV时未找到Final energy值\n";
        $mySheet->Cell($counter, 1) = "N/A";
    }
}
